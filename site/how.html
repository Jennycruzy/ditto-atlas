How it works

How it works

  1. Evidence. Every 2 hours the atlas reads recent real deposits into lending markets, savings vaults and pools on Base, Arbitrum, Optimism and Ethereum, recognising them through routers, smart wallets, Safes and bundlers.
  2. Recipe. Six families: Aave v3, ERC-4626 savings vaults (Morpho, Euler, Spark, Fluid), Compound v3, Moonwell, Lido, and Uniswap v3 / Aerodrome Slipstream liquidity. Each recipe builds standard calls.
  3. Checks. Real use, age, size, share-price history, pause and cap flags, token sanity, verified deployer, gas, and a simulated round trip.
  4. Plan and steps. One transaction per PayBox approval. Progress comes only from this plan's own transactions, so retries, lost sessions and double submits are safe.
  5. Proof. Exact amount out, receipt in, nothing else moved, allowance 0, exit open, gas paid.

Second opinions
